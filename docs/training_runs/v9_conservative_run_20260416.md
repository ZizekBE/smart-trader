## 结论与下一步

### r1 vs r2 对比

| 指标 | r1 | r2 | 变化 |
|------|----|----|------|
| Best eval reward | +0.3030 | **+0.8422** | +2.8x |
| Mean rollout reward | -67.78 | -57.59 | +15% |
| Entropy 最低点 | -0.547 | -0.314 | 改善 |
| Value loss 峰值 | ~180 | ~344 | 后期更严重 |
| 步数利用率 | 23%（46k） | 47%（94k） | +2x |
| 早停 update | 90 | 185 | patience=20 有效 |

### r1 初步结论

- v9 架构能正常训练，无运行时错误
- 在 step 20,480 出现有效学习信号（eval reward 首次转正 +0.3030）
- 但 policy 随后坍缩（entropy 大幅为负），value function 发散，未能维持改善
- 根因：lr 偏高 + entropy 约束偏弱，两者叠加导致 n_epochs=8 的强更新过拟合当前 rollout

### r2 结论

lr（3e-4→1e-4）+ entropy（0.02→0.03）调参后：
- Best eval 从 +0.30 提升至 +0.8422（+2.8x），调参有效
- Entropy 坍缩速度降低，update 90+ 后逐步恢复至 -0.05～-0.10
- 但 value loss 后期（update 100+）再次发散至 200-340，根本问题未解决
- 实际学习窗口仍仅在 update 5～85（约 40k steps），之后 policy 退化

### WF 评估结论

**r2 best_agent.pt 未能通过 shadow 门禁。**

关键诊断：
- **Mean Sharpe = -1.15**（门禁要求 > 0）：20 折中仅 10 折盈利，整体净值为负
- **高方差**：Std Return = 17.23%，最佳折 +23.35%，最差折 -37.19%，说明 policy 对市场状态极其敏感
- **高 Max DD**：均值 21.24%，最差折 40.26%，对 conservative 配置来说风险过高
- **结构性问题**：2026 年 1 月底至 2 月的连续亏损（fold 8–12）对应 ETH 急跌行情，policy 未能切换为空仓/防守；盈利折（fold 1, 13, 15, 20）集中在趋势明确的周

| 现象 | 根因 |
|------|------|
| 50% 胜率但负均值 | 亏损折的亏损幅度（-37%）远超盈利折的收益（+23%），风险不对称 |
| Max DD 超过 30% | policy 未有效使用 stop-loss 逻辑；risk_budget 在下跌时仍维持高仓位 |
| 近期折（fold 1–6）表现好于历史折 | policy 可能对近期数据有偏差（训练数据截至 2026-04-11） |

### 未解决问题与 r3 建议

| 问题 | 优先级 | 可能方向 |
|------|--------|---------|
| WF Mean Sharpe < 0 | **P0** | 从根本解决 value loss 发散：lr→5e-5，或 value head 独立低 lr 优化器 |
| 亏损幅度远大于盈利幅度 | **P0** | 强化 trade_penalty（0.02→0.05），或加入 max_dd 惩罚项 |
| n_epochs=8 更新过强 | **P1** | 降至 `--n-epochs 4`，降低每轮 policy 漂移 |
| eval 方差导致假阳性早停 | **P1** | `--eval-episodes 30`，或用滑动均值作为 best 判断依据 |
| 训练有效窗口仅 ~40k steps | **P2** | 探索 `--patience 30` + `--eval-episodes 30` 组合 |

**结论：v9 conservative r2 作为 RL v9 基准已记录，但不进入 shadow mode。建议以上述 r3 超参数继续迭代，或先优化 reward shaping 再重训。**
